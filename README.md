## ✨ Features

- 99.9% accurate ASL alphabet (A–Z) recognition  
- Works completely **offline**
- Real voice output using your computer's speaker (pyttsx3)  
- Smooth confidence-based letter locking (no jitter)  
- OpenCV interface with live instructions  
- Train your own model in minutes  

## 🚀 Quick Start (30 seconds)

```bash
